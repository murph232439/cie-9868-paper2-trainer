# 9868 Paper 2 写作训练站

面向学生的训练型网站，围绕 CIE 9868 Paper 2 的三类写作任务：

- A部分：议论文 / 讨论文
- B部分：描写文
- B部分：记叙文

网站不是资料站，而是训练站。学生需要按步骤完成审题、破题、论点、例子、Explain、结构和语言练习。

## 已有功能

- 三类题型直接进入题库，先选题再训练
- 每类题型保留独立技能地图，作为第二层训练
- 每关按步骤训练，完成后获得 XP
- 个人进度和能力统计
- 语言提示与全局语言升级库，按文体、题型和功能分类
- 语言卡预留学生作品来源字段，方便批改后持续收集
- 题库练习：议论文 31 题、描写文 27 题、记叙文 24 题
- 已加入 9868/23 真题，题库会显示具体来源
- 每道题都可以直接进入审题、破题、论点、例子和结构练习
- 议论文题库里每道题都有独立“审题训练”：题眼、改写争议、定义、立场、两个 point、例子和提纲
- 错题回炉
- 课堂投屏模式
- 真题 Boss：提纲模式 20 分钟，全文模式 60 分钟
- 所有进度保存在浏览器 localStorage

## 运行方法

在 `outputs/site` 目录启动一个本地静态服务器：

```bash
python3 -m http.server 4321
```

然后打开：

```text
http://localhost:4321
```

也可以直接双击 `index.html` 使用，但建议用本地服务器，方便浏览器稳定加载模块文件。
